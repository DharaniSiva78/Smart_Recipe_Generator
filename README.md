Smart Recipe Generator 

    Smart Recipe Generator is a simple, intelligent recipe suggestion app that generates meal ideas based on the ingredients you provide. It helps users decide what to cook with what they already have and reduces food waste.

Live Site : https://smart-recipe-generator-7wfl.vercel.app/recipes

Features

    Ingredient-based recipe generation — enter ingredients, get smart suggestions

    User-friendly interface — clean and simple design

    Expandable recipe database — easy to add more dishes

    Lightweight & fast — no heavy frameworks

Install dependencies:

    npm install 

Running the Project :

    npm start
